# simplemernapp

A simple insurance website built with Node.js and Express.

## Features
- Shows basic insurance plans
- Lets users submit a quote request
- Calculates and displays an estimated premium
- Lists submitted quote requests
- No authentication

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Open `http://localhost:3000`
